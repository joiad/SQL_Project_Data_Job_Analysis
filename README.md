# SQL Job Market Analysis

This project explores job application trends, skill demands, and salary distribution using SQL. The data is structured and analyzed using SQL queries including INSERT statements, JOINs, CTEs, and Window Functions.

## Tools Used
- SQL (PostgreSQL / MySQL)

## Key Highlights
- Inserted and cleaned job records in a structured format
- Performed analysis of in-demand roles and regions
- Supported career planning insights using real job market data

## File Description
- `INSERT INTO job_applied.sql` – A sample SQL script demonstrating the creation and population of job data for analysis.

## Outcome
Enabled structured analysis of job market trends and helped visualize demand by industry, region, and skillset.
